## 🎯 Purpose & Scope

---

## 📐 Invariants & Evidence Standards

All contributions, feedback, or visual adjustments must adhere to the following principles:

1. **Zero Fabrication Policy**:
   - Hardware claims must be strictly classified according to the 7-stage maturity lifecycle.
   - Simulated signals must never be presented as physical bench measurements.
   - Academic credentials and certifications must link directly to verifiable third-party providers (e.g. Credly).
2. **Visual Design Integrity**:
   - Palette: Lavender, soft violet, periwinkle, and deep purple engineering aesthetics.
   - Standalone assets: All SVG cards and diagrams must be self-contained with no fragile external CDN dependencies.
3. **Automated Verification**:
   - Before opening a PR, run the local asset and markdown validator:
     ```bash
     python scripts/validate_portfolio.py
     ```
